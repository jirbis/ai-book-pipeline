# Books by the project author

The book pipeline is designed for real editorial work: research, drafts, revisions, critique and publication-readiness checks. These books illustrate the author's publishing interests and the kinds of projects the workflow is intended to support.

## Author portfolio

- **[The Huna Guide: Practical Wisdom for Everyday Life](https://www.goodreads.com/book/show/246937716-the-huna-guide)** — practical, explanatory non-fiction.
- **[Surviving Crypto: Navigating the Psychological Traps of Trading](https://www.goodreads.com/book/show/246947889-surviving-crypto)** — research-informed non-fiction for readers interested in trading behavior.
- **[Stop Talking. Start Building: A Practical Method for Moving from Chat to Real Execution](https://www.goodreads.com/book/show/247509054-stop-talking-start-building)** — actionable, process-oriented guide.

These titles are listed under **Gregory Kneller** on [Goodreads](https://www.goodreads.com/author/show/67957835.Gregory_Kneller). The author has reported publishing books on Amazon Kindle, but **the individual Kindle product URLs/ASINs have not yet been independently verified**. Direct Amazon links should be added here once confirmed. Goodreads listings do not independently prove that every title was written using this repository's pipeline; do not claim that without per-title production evidence.

## How to use these examples

- A **non-fiction case study** should show the original outline, source references, author-voice settings, revision snapshots, editorial review and a final exported sample *with the author's permission*.
- A **fiction case study** should show character/world continuity, chapter revisions and critique decisions, not simply a cover.
- If the author supplies each book's verified Kindle ASIN, add a direct product listing link and factual edition metadata. Do not invent ratings, sales, endorsements or publication dates.
- Do not upload full copyrighted manuscripts, unpublished research, drafts, or private notes to this public showcase.

For the actual editing workflow, see [GitHub-backed book workspaces](../skills/book-authoring/references/github-workflow.md). GitHub hosts the manuscript source and collaboration; Amazon Kindle/KDP is a **separate publishing destination** and is not an automatic step of a Git commit or Pull Request.

# Review Checklist — The Science of Decision-Making

> Used by EDITOR and CRITIC agents to assess chapter and book quality.

## Non-Fiction Quality Criteria

### Structure and Organization
- [ ] Main thesis is clearly stated in each chapter
- [ ] Arguments follow a logical sequence (story → science → takeaway)
- [ ] Connections between ideas are explicit
- [ ] Transitions between sections are smooth
- [ ] Introduction and conclusion align with the chapter body
- [ ] "Decision Toolkit" box is present in every chapter

### Content
- [ ] Each claim is backed by a cited source
- [ ] Concrete examples illustrate every abstract concept
- [ ] Statistics and data points are accurate and sourced
- [ ] Quotes are accurately attributed
- [ ] No factual errors detected
- [ ] Technical terms are defined on first use

### Practicality
- [ ] Each chapter has an actionable takeaway
- [ ] Advice is concrete and specific (not vague platitudes)
- [ ] "Decision Toolkit" technique is immediately usable
- [ ] Examples are drawn from relatable, everyday situations

### Engagement
- [ ] Opening hook grabs attention within the first paragraph
- [ ] Language is lively and varied
- [ ] Stories and anecdotes are vivid and relevant
- [ ] Pacing alternates between narrative and explanation
- [ ] Chapter ending creates momentum for the next chapter

### Clarity
- [ ] Understandable to a reader with no psychology background
- [ ] No jargon used without explanation
- [ ] Sentences average 15–20 words; paragraphs are 2–4 sentences
- [ ] Active voice predominates
- [ ] Analogies clarify rather than confuse

## Cross-Cutting Quality

### Style
- [ ] Voice consistent with author-voice.md throughout
- [ ] Tone matches style-guide.md
- [ ] No filler words or padding
- [ ] Repetition is intentional (callbacks to chapter opening)
- [ ] Metaphors and analogies are drawn from everyday life

### Grammar and Mechanics
- [ ] Spelling correct throughout
- [ ] Punctuation consistent (Oxford comma, em-dashes, en-dashes)
- [ ] Subject-verb agreement
- [ ] No dangling participles
- [ ] Numbers formatted per style guide

### Formatting
- [ ] Heading hierarchy follows style guide (# ## ### ####)
- [ ] Bold/italic used consistently per style guide
- [ ] Lists are grammatically parallel
- [ ] Blockquotes used only for direct source quotes
- [ ] Paragraph length is appropriate (2–4 sentences)

### Consistency
- [ ] Names and terms spelled the same throughout
- [ ] Citation format is uniform (APA 7th)
- [ ] Dates and numbers follow a single convention
- [ ] No contradictions between chapters
- [ ] Timeline of referenced studies is accurate

### Technical Aspects
- [ ] Chapter metadata (status, version, word count) is up to date
- [ ] All sources appear in bibliography.md
- [ ] Word count is within target range
- [ ] Editor notes are documented
